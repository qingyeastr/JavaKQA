# JavaKQA

## 基于 RAG 的编程技术文档问答助手

JavaKQA 是一个面向 Java 后端技术生态的智能问答助手系统，项目目标是基于官方技术文档构建可检索、可追溯、可持续扩展的知识库，并通过 RAG（Retrieval-Augmented Generation，检索增强生成）能力实现高质量编程问答。

本系统聚焦 Spring Boot、Spring Framework、MyBatis、RocketMQ、Redis、MySQL 等常见后端技术，围绕“文档采集与切片、知识检索、智能问答、会话管理、反馈优化、数据分析、系统配置”七大模块完成整体设计与实现。

当前仓库处于项目初始化阶段，后端已完成 Spring Boot 基础骨架搭建，前端、知识库构建、检索链路与 RAG 问答能力将按 README 中的设计逐步落地。

## 项目目标

1. 构建面向 Java 后端技术文档的领域知识库。
2. 支持对官方文档内容进行解析、切片、索引和统一管理。
3. 支持关键词检索、语义检索和混合检索，提高召回质量。
4. 基于检索结果与大模型生成能力，实现可引用知识片段的智能问答。
5. 支持多轮对话与上下文记忆，增强交互连续性。
6. 通过用户反馈和数据分析持续优化知识库与问答效果。

| --- | --- | --- |

| 用户反馈 | 点赞、点踩、纠错、补充 | 采集反馈数据并反哺系统优化 |
| 数据分析 | 问答统计、热点问题、知识缺口 | 展示系统运行状态与内容薄弱点 |
| 系统配置 | 模型配置、检索参数、用户管理 | 支撑后台管理与运行参数调优 |

## 系统总体架构

```text
官方技术文档
    -> 文档采集
    -> 文档解析与清洗
    -> 文本切片与元数据提取
    -> 知识库存储（文档表 / 分片表 / 检索索引）
    -> 检索层（关键词检索 + 语义检索 + 重排）
    -> RAG 问答链路（查询改写 + 上下文拼接 + 大模型生成）
    -> Web 前端展示（问答、知识库管理、反馈、数据分析）
```

- Java 17

- Spring MVC

- Maven

### 前端

- Vue 3
- Vite
- Web 页面交互式问答界面

### 数据与检索

- MySQL：结构化数据存储
- Redis：缓存、会话上下文、热点数据加速
- 向量库或向量检索方案：用于语义召回
- 全文索引方案：用于关键词检索与混合检索

- Embedding 模型：用于文档向量化和查询向量化
- 大语言模型：用于答案生成、查询改写、结果总结
- RAG 流程：检索召回 -> 相关片段筛选 -> 上下文增强 -> 生成答案

## 关键业务流程

### 1. 文档入库流程

1. 采集官方文档页面或导入文档内容。
2. 对原始文档进行格式清洗、正文抽取和噪声过滤。
3. 按段落、标题、代码块等结构进行切片。
4. 为每个知识片段补充来源、标题、章节、标签等元数据。
5. 将文档及切片存入数据库，并建立关键词索引和向量索引。

### 2. 问答流程

1. 用户在前端输入问题。
2. 系统执行查询预处理与查询改写。
3. 检索模块基于关键词检索和语义检索召回相关知识片段。
4. 对候选片段进行相关性排序与去重。
5. RAG 模块将高相关片段拼接到提示词上下文中。
6. 大模型生成答案，并返回引用来源或相关文档片段。
7. 用户对答案进行反馈，系统记录用于后续优化。

### 3. 多轮对话流程

1. 保存当前会话问题、答案和引用片段。
2. 结合上下文识别省略问题和连续追问。
3. 根据会话历史补全查询语义，提升多轮问答准确率。

## 建议的数据对象

为支撑系统功能，后续可围绕以下核心对象进行数据库建模：

- 文档表：保存文档来源、标题、技术分类、原始链接、抓取时间、解析状态
- 分片表：保存知识片段文本、所属文档、分片序号、标签、向量索引标识
- 会话表：保存会话信息、用户标识、创建时间、最近活跃时间
- 消息表：保存用户问题、系统回答、引用片段、耗时、置信度
- 反馈表：保存点赞点踩、纠错内容、补充说明
- 检索日志表：保存查询词、召回结果、点击情况、问答结果
- 系统配置表：保存模型参数、召回阈值、TopK、提示词模板等配置项

## 推荐页面规划

## 项目特色
