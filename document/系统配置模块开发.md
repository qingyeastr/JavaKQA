# 系统配置模块开发记录

## 1. 模块定位

系统配置模块用于管理问答系统运行过程中的关键参数与后台控制项，服务于模型接入、检索调优、用户权限控制以及系统级开关管理。

该模块不直接参与用户问答展示，但会影响知识检索、RAG 生成、上下文记忆、日志记录和后台运维能力，是后台管理端的基础支撑模块。

## 2. 开发目标

1. 支持配置大模型、Embedding 模型及相关访问参数。
2. 支持配置检索策略，包括关键词检索、语义检索、混合检索参数。
3. 支持配置问答链路中的 Prompt 模板、TopK、相似度阈值等运行参数。
4. 支持基础用户管理与角色权限控制。
5. 支持配置缓存、日志、开关项等系统级参数。

## 3. 功能范围

### 3.1 模型配置

- 配置大语言模型名称、接口地址、API Key、超时时间
- 配置 Embedding 模型名称、向量维度、接口地址
- 配置默认生效模型与备用模型
- 支持启用、禁用、切换模型配置

### 3.2 检索参数配置

- 配置关键词检索 TopK
- 配置语义检索 TopK
- 配置混合检索权重
- 配置重排开关与重排数量
- 配置相似度阈值、最低召回条数

### 3.3 问答参数配置

- 配置系统提示词模板
- 配置是否启用查询改写
- 配置多轮对话上下文窗口长度
- 配置答案最大长度
- 配置是否展示引用来源

### 3.4 用户与权限管理

- 后台管理员账号管理
- 普通用户状态管理
- 角色划分与接口访问控制
- 登录信息与操作日志留痕

### 3.5 系统开关配置

- 是否启用知识库上传功能
- 是否启用用户反馈功能
- 是否启用数据分析面板
- 是否启用敏感词过滤或内容审核

## 4. 页面设计建议

系统配置页面建议分为以下几个区域：

1. 模型配置页签：管理大模型与向量模型
2. 检索配置页签：管理召回、重排、阈值等参数
3. 问答配置页签：管理 Prompt、上下文窗口、答案展示策略
4. 用户管理页签：管理账号、角色、状态
5. 系统开关页签：管理功能启用与停用状态

页面交互建议：

- 左侧为功能分类菜单，右侧为配置表单或表格
- 支持查看当前生效配置
- 支持编辑、保存、重置、启用、停用操作
- 关键配置修改后支持二次确认

## 5. 数据设计建议

以下字段类型按 PostgreSQL 设计，时间字段统一使用 timestamp，布尔开关优先使用 boolean。

### 5.1 system_config 表

建议字段：

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint | 主键 |
| config_key | varchar(100) | 配置项唯一标识 |
| config_name | varchar(100) | 配置项名称 |
| config_group | varchar(50) | 配置分组，如 model、retrieval、prompt、system |
| config_value | text | 配置值 |
| value_type | varchar(20) | 值类型，如 string、number、boolean、json |
| description | varchar(255) | 配置说明 |
| is_enabled | boolean | 是否启用 |
| created_at | timestamp | 创建时间 |
| updated_at | timestamp | 更新时间 |

### 5.2 sys_user 表

建议字段：

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint | 主键 |
| username | varchar(50) | 用户名 |
| password | varchar(100) | 密码密文 |
| role_code | varchar(30) | 角色编码 |
| status | smallint | 账号状态 |
| last_login_time | timestamp | 最近登录时间 |
| created_at | timestamp | 创建时间 |
| updated_at | timestamp | 更新时间 |

### 5.3 operation_log 表

建议字段：

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint | 主键 |
| operator_id | bigint | 操作人 ID |
| module_name | varchar(50) | 模块名称 |
| operation_type | varchar(50) | 操作类型 |
| operation_content | text | 操作内容 |
| created_at | timestamp | 操作时间 |

## 6. 后端接口建议

### 6.1 配置管理接口

- GET /api/admin/config/list：查询配置列表
- GET /api/admin/config/{id}：查询配置详情
- POST /api/admin/config/save：新增配置
- PUT /api/admin/config/update：更新配置
- PUT /api/admin/config/enable/{id}：启用配置
- PUT /api/admin/config/disable/{id}：停用配置

### 6.2 用户管理接口

- GET /api/admin/user/list：查询用户列表
- POST /api/admin/user/save：新增用户
- PUT /api/admin/user/update：更新用户
- PUT /api/admin/user/status/{id}：修改用户状态

### 6.3 日志接口

- GET /api/admin/log/list：查询操作日志

## 7. 实现建议

### 7.1 后端建议

- 使用 Spring Boot 构建后台管理接口
- 配置项建议按分组管理，便于页面展示与缓存刷新
- 高频读取配置项建议加入 Redis 缓存
- 关键配置变更需要记录操作日志

### 7.2 前端建议

- 使用 Vue 3 构建后台配置页面
- 表单项按配置类型动态渲染输入组件
- 对 JSON 类型配置增加格式校验
- 对模型与检索配置提供测试按钮，便于验证配置有效性

## 8. 校验规则建议

- config_key 必须唯一
- 数值型配置需要限制最小值和最大值
- 布尔型配置统一使用 true/false 或 0/1
- JSON 类型配置保存前必须完成格式校验
- 涉及密钥类配置时，页面展示应做脱敏处理
