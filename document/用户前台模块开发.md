# 用户前台模块开发记录

## 1. 模块定位

用户前台模块面向普通使用者，负责承接 README 中规划的智能问答、知识库管理、文档检索、对话管理、反馈管理、数据分析、系统配置等前台产品页面。

该模块不负责后台配置维护，也不直接承载 PostgreSQL 管理逻辑。当前阶段先完成页面骨架、登录入口与模块导航，后续再逐步接入真实问答、检索与知识库接口。

## 2. 模块拆分原因

将普通用户前台与 system-config 后台拆为独立模块，主要基于以下考虑：

1. 职责边界不同。system-config 是后台管理端，user-portal 是普通用户使用端。
2. 演进节奏不同。前台页面后续可能替换为 Vue 3 + Vite，而后台可继续保持服务端渲染。
3. 运行配置不同。后台依赖 PostgreSQL 与配置表，前台当前阶段只需原型展示与登录态。
4. 部署方式不同。后续可以独立部署前台与后台，而不是把两类页面混在同一个应用里。

## 3. 当前模块结构

- framework：公共基础模块
- system-config：后台系统配置模块
- user-portal：普通用户前台模块

user-portal 当前采用 Spring Boot + Thymeleaf 方式搭建原型页面，模块路径位于 user-portal。

## 4. 当前实现内容

### 4.1 登录入口

- 前台登录地址：http://localhost:8081/login
- 演示阶段支持任意用户名登录
- 演示阶段统一密码：123456
- 登录页右上角可跳转至后台管理员登录页

### 4.2 页面模块

当前已提供以下页面骨架：

1. 产品概览
2. 智能问答
3. 知识库管理
4. 文档检索
5. 对话管理
6. 反馈管理
7. 数据分析
8. 系统配置说明页

### 4.3 交互方式

- 左侧固定侧边栏提供模块导航
- 右侧内容区根据当前模块切换展示页面原型
- 顶部保留管理员入口跳转按钮
- 登录后通过 Session 维护前台演示登录态

## 5. 当前路由设计

### 5.1 页面路由

- GET /login：前台登录页
- POST /login：处理前台登录
- POST /logout：退出前台
- GET /：产品概览页
- GET /qa：智能问答页
- GET /knowledge：知识库管理页
- GET /retrieval：文档检索页
- GET /conversation：对话管理页
- GET /feedback：反馈管理页
- GET /analytics：数据分析页
- GET /settings：系统配置说明页

### 5.2 跳转关系

- system-config 登录页右上角跳转至 user-portal 登录页
- user-portal 登录页和页面右上角均可跳转至 system-config 管理员登录页

## 6. 配置说明

user-portal 当前默认配置位于 user-portal/src/main/resources/application.properties：

- server.port=8081
- app.admin-base-url=http://localhost:8080
- spring.thymeleaf.cache=false

后台 system-config 则通过 app.portal-base-url=http://localhost:8081 反向跳转到前台登录页。

## 7. 当前限制

目前 user-portal 仍是前台原型阶段，以下能力尚未接入真实后端：

- 智能问答接口调用
- 检索结果真实查询
- 知识库文档导入与状态同步
- 会话历史持久化
- 反馈数据保存与回流
- 数据分析实时统计

因此当前模块的目标是先把前台信息架构、导航关系与页面布局稳定下来。
